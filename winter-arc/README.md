## Concept — Grizzly Crest
Vintage National Park poster x banknote engraving. Grizzly merged with Rockies, pine forest, brass filigree. Arched WINTER ARC + ribbon ASH ALLEN TRAINING. Micro-type: SCIENCE-DRIVEN STRENGTH & ENDURANCE / CALGARY ALBERTA EST 2020 / DROP 001 MMXXV

## Palette (3 inks on black)
- Cream #F1EAD7 — Pantone Warm Gray 1 C / 4685 C
- Deep Pine #1B3329 — Pantone 3435 C / 5535 C (halftone shading)
- Brass #C2A46A — Pantone 7504 C / Metallic 871 C (filigree, small type)

## Sizing
- Hoodie: 14" W x 16" H centered, 2" below back collar (below hood seam)
- Tee: 13" W x 15" H, trim outer filigree 6% to avoid shoulder seam

## Press
White underbase, then cream, pine, brass last. 230 mesh, 55 LPI halftone, 300 DPI vectors. Trap pine 0.25pt over cream.
